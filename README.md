# Projetos Laravel

Repositório dedicado a centralizar meus projetos desenvolvidos com **Laravel**.

Este espaço substitui parte do que antes ficava no repositório `PHP-student`, reunindo agora especificamente os projetos construídos com o framework, à medida que forem sendo desenvolvidos e organizados aqui.

## 📌 Status

🚧 Repositório em construção — ainda não há projetos publicados.

## 🎯 Objetivo

- Reunir em um único lugar os projetos Laravel desenvolvidos para estudo e prática
- Servir como portfólio da evolução com o framework (Eloquent, Migrations, Controllers, Middleware, Repository Pattern, etc.)
- Facilitar a organização e consulta de projetos anteriores

## 🛠️ Tecnologias

- PHP
- Laravel
- MySQL / SQL
- Tailwind CSS

## 📂 Estrutura (em breve)

Conforme os projetos forem adicionados, cada um terá sua própria pasta (ou branch/repositório vinculado) com um README específico detalhando:

- Descrição do projeto
- Funcionalidades
- Tecnologias utilizadas
- Como rodar localmente
